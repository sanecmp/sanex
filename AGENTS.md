# sanex

Перед работой прочитай [IDLE.md](IDLE.md) и соблюдай его правила.

- sanex — системная служба sanecmp на компьютере ребенка.
- Написан на Python 3.12+ для Debian-based Linux x86-64 с GNOME и systemd/logind.
- Учитывает пользовательские сеансы и приложения, применяет ограничения.
- Исполняет сохраненные настройки автономно при недоступности sanea.
- Хранит конфигурацию, состояние и события в JSON и JSONL без SQLite.
- Синхронизируется с sanea по HTTPS с mTLS.
- Получает окна и закрывает их через AT-SPI.
- Дистрибутив называется `sanecmp-sanex`; пользовательский индикатор входит в тот же пакет.
